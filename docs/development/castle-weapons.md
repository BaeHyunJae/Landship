# 성 수동 무장

아군 이동 성을 선택하고 Q 일반 대포, W 산탄총, E 발리스타를 누르거나 우측 하단 무장 버튼을 클릭한다. 범위를 확인한 뒤 지면을 좌클릭해 시전한다. 우클릭·Esc는 취소한다. 생산 단축키는 F1 창병·F2 궁병·F3 기마병으로 옮겼다.

기존 성의 근접 기본 공격과 자동 공격은 제거했다. 성은 이동·정지·위치 사수와 수동 무장을 사용하며, 기본 공격이 필요한 공격 이동·적 우클릭 공격에는 참여하지 않는다. 혼합 선택에서는 병력의 기존 공격 명령을 유지한다. 공통 기본 공격 컴포넌트는 부모의 사망 정리 호환성을 위해 남기되 성에서는 구성·활성화하지 않는다.

## 일반 대포

성 중심에서 사거리 1200cm 안의 지면을 지정한다. 지정 지점에서 반경 250cm 안에 중심점이 들어온 적 병력·성·거점에 즉시 60 피해를 준다. 쿨타임은 8초다. 사거리 밖 클릭은 실패하고 조준 상태를 유지하며 쿨타임을 소모하지 않는다. 파란 큰 원은 시전 가능 사거리, 작은 원은 피해 구역이다. 사거리 밖 조준은 붉게 표시한다.

## 산탄총

성에서 마우스 방향으로 길이 600cm·전체 각도 70도의 부채꼴 범위에 35 피해를 준다. 쿨타임은 6초다. 살아남은 적 일반 병력만 바깥 방향으로 밀어낸다. 현재 넉백은 수평 초속 650cm·상향 초속 180cm의 LaunchCharacter 방식이다. 실제 이동 거리는 중력·지형·충돌의 영향을 받는다. 성과 건물에는 피해만 적용한다.

명령 컴포넌트가 넉백 동안 추적·이동·공격 실행을 보류하고 착지 후 원래 명령을 재개한다. 기존 명령과 예약은 유지하며, 넉백 중 새 명령을 받아도 강제 이동 자체를 취소하지 않는다. 따라서 AI의 이동 요청이 넉백 속도를 덮어쓰지 않는다.

## 발리스타

마우스 방향으로 최대 1800cm를 직진하는 비유도 투사체를 발사한다. 속도는 1800cm/s, 충돌 반경은 18cm이며 첫 적 병력·성·거점 중 하나에 160 피해를 준 뒤 제거한다. 쿨타임은 10초다. 지정 목표만 맞히는 기존 궁병 화살과 구분해 첫 적 충돌 모드를 사용한다. 아군·시체·지형·장식물은 통과한다. 발사한 성이 파괴되어도 저장된 진영·피해로 비행을 계속하며 최대 비행 거리에서 제거된다.

## 공통 규칙과 구현 위치

세 무장은 독립 쿨타임을 사용하며 마나·자원 비용은 없다. 정상 시전이면 적을 맞히지 못해도 쿨타임을 소모한다. 조준만 하거나 취소한 경우, 잘못된 방향·범위·초기 수치, 성 선택 상실·파괴 상태에서는 시전하지 않는다. 성을 바꿔 선택하면 조준을 취소한다. 여러 아군 성을 선택한 경우 첫 성 한 곳에서만 조준·발사한다. 범위 공격의 거리·각도는 수평면의 액터 중심을 기준으로 판정한다. 아군은 개발용 오폭 허용 설정과 무관하게 피해·넉백 대상에서 제외한다.

`ULSCastleWeaponComponent`가 무장 상태·쿨타임·피해·넉백을 소유하고 `ALSPlayerController`가 조준 상태와 입력을 담당한다. `ALSRTSHUD`는 범위와 시전 직후 표시를 그린다. HUD는 직접 피해나 쿨타임을 변경하지 않는다. 피해는 기존 공통 체력 컴포넌트에 전달한다. 무장 수치는 아래 Data Asset의 레벨별 설정에서 조정한다. 현재 수치는 시험값이다.

## 활성 상태와 레벨별 성장

각 성은 무장 ID별 `FLSCastleWeaponState`를 가진다. 해금 여부·활성 여부·현재 레벨·다음 사용 가능 시각을 분리하며, 공유 Data Asset은 런타임 상태를 저장하지 않는다. 기본 시험 맵은 세 무장을 모두 해금·활성·1레벨로 시작한다. 성의 Weapons 컴포넌트에서 `Initial States`를 편집하면 성별 시작 상태를 정할 수 있다. PIE의 `States`는 조회용이며 플레이 중 변경은 아래 요청을 사용한다.

`Content/Landship/Castle/Data`의 `DA_Cannon`, `DA_Shotgun`, `DA_Ballista`가 무장별 레벨 수치를 가진다. `Levels` 배열의 첫 항목은 1레벨이며 항목 수가 최대 레벨이다. 시험 데이터는 3레벨까지 준비했다. 대포는 피해 60/80/100·반경 250/300/350, 산탄은 피해 35/45/55·각도 70/80/90, 발리스타는 피해 160/200/240·사거리 1800/2000/2200으로 증가한다. 다른 수치도 각 레벨에서 직접 지정할 수 있다. 기본 쿨타임은 레벨에 관계없이 기존 8/6/10초다.

외부 C++·Blueprint에서는 다음 요청과 조회를 사용한다.

- `UnlockWeapon`, `SetWeaponUnlocked`: 해금·잠금. 활성 선택과 레벨은 유지한다.
- `SetWeaponEnabled`: 활성·비활성. 잠긴 무장의 활성화 요청은 실패한다.
- `UpgradeWeapon`: 해금된 무장을 한 레벨 강화한다. 비활성 무장도 강화할 수 있다.
- `GetWeaponState`, `GetMaxLevel`, `GetResolvedSettings`: 현재 상태·최대 레벨·현재 레벨의 최종 수치를 조회한다.
- `OnWeaponStateChanged`: 실제 상태 변경당 한 번 통지한다. 같은 상태를 다시 지정하거나 실패한 요청은 통지하지 않는다. 알림 중 변경 재진입은 Busy로 거부한다.

비활성화·잠금은 해당 무장의 조준을 즉시 취소한다. 강화 시 조준·명중 판정은 새 레벨의 동일한 수치를 조회한다. 상태 변경과 강화는 진행 중인 쿨타임을 초기화하거나 단축하지 않으며 새 쿨타임 수치는 다음 시전부터 적용한다. 발사된 투사체와 시전 직후 범위 표시는 발사 당시 수치를 유지한다. 누락·잘못된 레벨 데이터는 기본값으로 대체하지 않고 사용·강화를 차단한다. 강화 비용 차감이나 별도의 강화/토글 화면은 이번 구조에 포함하지 않았다.

무장 정의는 `Weapon Definitions`에서 지정하며, 코드 생성 단계에서는 `SetWeaponDefinitions`를 사용할 수 있다. 플레이 시작 후 정의 교체는 허용하지 않는다. `setup-castle-weapon-data.py`는 없는 시험용 Data Asset만 만들며 기존 에셋에서 편집한 수치를 덮어쓰지 않는다.

## 검증 방법

자동 검사 `Landship.Castle.Weapons`는 원형·부채꼴 범위, 아군 제외, 일반 병력 넉백과 구조물 제외, 발리스타 첫 적 충돌·아군/지형 통과·비행 거리, 조준 취소·실패·선택 상실·성 파괴와 독립 쿨타임을 검사한다.

`HMH_TroopTypes`를 `-HMHCastleWeaponsTestExit`로 실행하면 실제 지면에서 세 무장과 무장/생산 버튼을 검사한다. 기존 이동·전투 검사는 `-HMHTroopTypesTestExit`를 사용한다. 무장 검증 액터는 일반 플레이에서 제거하며 쿠킹 제외 대상으로 지정한다. 전용 테스트 맵과 데이터만 갱신하고 기존 HMH·팀원 맵은 수정하지 않는다.

Editor 빌드와 전체 자동 테스트 42개가 통과했다. 실제 무장 실행 검사도 실패 없이 완료했으며 추적 AI를 켠 병력의 넉백·착지 후 추적 재개·예약 보존을 확인했다. 원형·부채꼴·직선 표시와 무장/생산 패널을 렌더링해 확인했다. 키보드 입력과 마우스 포커스 조합 전체, 다른 해상도와 Shipping 패키징은 별도 확인 대상이다. 적 성의 자동 무장 AI는 추가하지 않았다.

- 자동 테스트: `Saved/Automation/CastleWeaponsFinal/index.json`
- 실제 무장 실행 검사: `Saved/Logs/HMHCastleWeaponsVerified.log`
- 기존 이동·집결 회귀 검사: `Saved/Logs/HMHCastleWeaponsFinalRegression.log`

성장 구조 적용 후 Editor 빌드와 전체 자동 테스트 46개가 통과했다. `Landship.Castle.Progression`은 상태 변경·조준 취소·알림/재진입·최대 레벨·잘못된 데이터·강화 범위/피해·진행 중 쿨타임과 투사체 스냅샷을 검사한다. 실제 맵 검사 25개도 통과했고 HUD의 Lv 2/3·Disabled·Locked 및 잠금 중 쿨타임 표시를 렌더링해 확인했다.

- 성장 자동 테스트: `Saved/Automation/WeaponProgression/index.json`
- 실제 무장/상태 검사: `Saved/Logs/HMHWeaponProgression.log`
- 기존 이동·집결 회귀 검사: `Saved/Logs/HMHWeaponProgressionRegression.log`
