# 의무병 마나와 치유 분산 확인

## 언제 쓰는가

TABS 의무병의 마나 소모·재생과 단일 대상 치유 중첩 방지를 확인할 때 사용한다.

## 준비

- 변경된 C++ 모듈을 빌드한 에디터와 `Content/Developers/HMH/TABS/L_TABS` 맵.
- 의무병의 조정값은 `ULSMedicComponent`의 `Medic|Mana` 기본 설정을 사용한다. 병력 체력·이동 속도는 기존 DataTable을 사용한다.

## 순서

1. 병력과 의무병을 배치하고 머리 위 MP 표시를 확인한다. 준비 단계에서 기다려도 값이 증가하지 않아야 한다.
2. 전투를 시작하고 병력이 피해를 받게 한다. 빔이 연결된 의무병의 마나가 회복량에 비례해 감소하는지 확인한다.
3. 부상자는 한 명이고 의무병은 여러 명인 상황을 만든다. 같은 대상에게 동시에 여러 치유 빔이 연결되지 않아야 한다.
4. 여러 병력이 부상당한 상황을 만든다. 의무병이 이미 치료 중인 대상을 피하고 다른 부상자에게 연결하는지 확인한다.
5. 치유 중 대상이 멀어지거나 사망하게 한다. 이전 권한을 반납하고 빔을 끊는지 확인한다.
6. 마나 고갈까지 전투를 유지한다. 충분한 마나가 다시 모일 때까지 빔을 끄고, 다른 의무병은 해당 환자를 치료할 수 있어야 한다.
7. 전투 종료 후 편성을 복원한다. 시작 마나로 준비되고 이전 환자·치유 권한이 남지 않는지 확인한다.

## 성공 확인

- 실제 회복량에만 마나 비용이 적용되고, 최대 체력 초과분이나 거부된 회복에는 비용이 남지 않는다.
- 마나가 적으면 잔량으로 가능한 만큼만 회복하며 음수가 되지 않는다.
- 단일 환자의 의무병 치유 권한은 한 명에게만 발급되고, 중복·과거 권한 반환은 새 연결을 해제하지 않는다.
- 접근 중인 먼 목표를 독점하지 않으며 치유 거리에서 권한을 획득한다.
- 전투가 비활성 상태이거나 풀에 보관 중인 의무병은 마나를 재생하거나 치유하지 않는다.
- 이 절차는 동작 확인용이며 수치의 균형이나 성능 개선을 보장하는 기준은 아니다.
