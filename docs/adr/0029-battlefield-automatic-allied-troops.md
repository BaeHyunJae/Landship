# 0029. 전장 아군 병력의 직접 명령을 자동 교전과 성 추종으로 전환한다

- 상태: 채택
- 관련: [TABS형 성 대결 프로토타입 제작 (TASK-53)](https://app.notion.com/p/40dd5512e30a81e08ac8c527ec57a130)

## 동기

실제 전장의 성과 병력을 함께 조작하는 부담을 줄이고, 개별 이동·공격 명령 없이 병력이 성을 따라가다 적을 만나면 싸우는 흐름을 검토한다.

## 결정

BattlefieldSetup에서 자동 아군 병력 모드를 기본으로 켠다. 전장 상태가 이를 보관하고, Controls의 기존 OrderComponent가 아군 ALSUnit의 이동과 공격을 한 곳에서 실행한다. 직접 명령 요청과 명령 UI의 조작 권한은 같은 자동 모드 판정으로 거부한다. 성은 직접 조작 권한을 유지한다.

적 탐색·유지는 병사 자신의 시야 반경과 아군 공유 시야를 모두 통과해야 한다. 적이 없으면 전장에 지정한 플레이어 성 주변을 추종한다. 추종 간격과 재출발 여유는 데이터로 조정하고, 경로 탐색·공격 위치·사거리·지뢰 회피·성 진로 양보·넉백·승패 정지는 기존 기능을 사용한다.

추종 방향과 병력별 자리는 성의 Escort 컴포넌트가 공유한다. 실제 수평 속도로 전후방을 정하고 정지하면 마지막 방향을 유지한다. 기본 전방 병종은 창병·기병·궁병이고 다른 병종은 후방을 사용한다. 병력별 자리는 교전 중에도 유지하고 빈자리만 재사용한다. 병력은 목적지를 받아 자기 NavData와 경로를 검사한다. 성보다 느린 병력의 속도를 자동으로 보정하지 않는다.

성이 실제 충돌한 같은 진영 지상 병력은 성 이동 컴포넌트가 지면·충돌을 확인하며 수평으로 밀어낸다. 자동 병력은 접촉 후 잠깐 이동을 보류하고 기존 표적과 자리는 유지한다. 통행 가능한 밀기 공간이 없는 경우 성도 정지하며, 유닛 충돌을 무시하거나 지형을 넘어 순간이동시키지 않는다.

## 결과

전장 설정이 없는 TABS 전용 모드에는 이 자동 모드가 적용되지 않는다. 아군 병력은 정보 확인 대상으로 선택할 수 있지만 직접 이동·공격·정지·수비·해제 명령은 받지 않는다. 바리케이드와 무장 상태 지뢰도 자동 획득 설정이 켜져 있으면 공격 후보가 된다. 자동 병력은 기존 TABS 병종 컴포넌트의 교전 지시를 실행해 치유·포격·자폭·돌격을 재사용한다.

## 검토한 대안

- TABS 게임 모드가 실제 전장 병력까지 지휘한다. 두 게임 모드의 승패·지역·편성 수명과 이동 제어가 결합된다.
- 자동 판단이 매번 플레이어 명령을 제출한다. 직접 명령 차단과 내부 명령 허용을 구분하는 추가 경로가 필요하고 기존 명령 예약과 충돌할 수 있다.
