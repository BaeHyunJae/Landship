# 0002. 일반 공격의 같은 진영 피해를 공통 오폭 정책으로 제어한다

- 상태: 채택
- 관련: [TASK-39 전투 기반 클래스와 공통 규칙 구현](https://app.notion.com/p/408d5512e30a81d09f90ceea29d8fac8), [TASK-41 성 무장 조준·발사와 쿨타임](https://app.notion.com/p/408d5512e30a813581e7c761579dc947), [TASK-47 경로 장애물](https://app.notion.com/p/408d5512e30a8141aad7cf57a86658c8)

## 동기

공통 체력 처리는 오폭 허용 설정을 제공하지만 기본 투사체와 성 무장이 같은 진영을 명중 대상에서 먼저 제외해 설정이 실제 공격에 반영되지 않는다. 공격 종류와 진영에 관계없이 같은 설정으로 오폭을 제어하기 위해 명중 후보와 피해 처리가 같은 정책을 사용한다.

## 결정

자동 표적은 상대 진영만 고르되, 일반 공격의 같은 진영 피해는 `bAllowFriendlyFire`로, 자기 피해는 독립된 `bAllowSelfDamage`로 제어하며 두 기본값은 true를 유지한다. 일반 직선탄은 발사자를 제외하고 경로에서 처음 만난 살아 있는 전투 대상에 명중하며 오폭 금지 시 같은 진영을 통과하고, 장애물을 지정한 탄은 같은 진영도 물리적으로 막되 피해만 설정에 따른다. 대포의 범위 피해와 산탄의 실제 피해에 따른 넉백도 같은 정책을 따르며, 지뢰 폭발의 환경 위험 정책은 유지한다.

## 결과

오폭 허용 시 병력이 같은 편의 사격을 가로막아 피해를 받고, 적도 자기 바리케이드를 손상시키거나 자기 지뢰를 폭발시킬 수 있다. 대포는 자기 피해가 켜져 있으면 발사한 성에도 피해를 주므로 가까운 지점 사격의 위험을 감수한다.

## 검토한 대안

- 공격마다 같은 진영을 항상 명중 대상에서 제외한다: 공통 오폭 설정이 실제 공격의 같은 진영 피해를 제어해야 한다는 요구를 충족하지 못한다.
