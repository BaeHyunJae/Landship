# 0005. 성 무장의 입력 대상은 선택 대신 전장 설정으로 정한다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

병력을 선택해 명령하는 동안에도 성 무장을 사용하고 성의 체력·무장 상태를 확인해야 한다. 선택된 액터를 성 무장의 대상으로 삼으면 병력과 성을 반복해서 재선택해야 하며, 상시 상태 표시도 선택에 따라 사라진다.

## 결정

성 무장의 Q/W/E 입력과 상시 성 상태 표시의 대상은 현재 선택 대신 유효한 전장 설정에 지정된 아군 성으로 정한다. 무장 조준·발사 중에도 병력 선택과 명령 큐를 유지한다. 기존 선택 조회 API와 선택 기반 명령 카드의 의미는 보존한다.

## 결과

Q/W/E는 선택한 병종과 무관하게 성 무장에 사용되며, 전역 입력과 성의 명령 카드가 같은 키를 두 번 실행하지 않도록 해야 한다. 선택 유효성 대신 전장 성의 수명·전투 종료·무장 상태를 조준의 모든 단계에서 검사해야 한다.
