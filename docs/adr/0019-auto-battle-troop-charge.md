# 0019. 자동 전투 병종 돌격 상태의 소유

- 상태: 채택
- 관련: [병력 작업](https://app.notion.com/p/408d5512e30a81d09f90ceea29d8fac8)

## 동기

기마병의 도움닫기·명중과 창병의 일회성 대비가 여러 프레임 동안 유지되어야 한다. 기존 RTS 명령 처리와 공격 애니메이션에 상태를 넣으면 자동 전투와 직접 조종의 책임이 섞인다.

## 결정

각 병력은 병종에 맞는 전투 컴포넌트 하나를 소유한다. 공통 기반은 활성 수명과 경직을, 기병 컴포넌트는 돌격을, 창병 컴포넌트는 대비·방어·반격을 소유한다. 궁병은 공통 기반을 사용한다. Match는 공통 교전 판단 결과를 실행하고 병종별 분기를 두지 않는다. 돌격은 공통 방어 결과를 받아 피해를 적용하므로 기병 구현이 창병 구현에 의존하지 않는다. 공통 공격은 다음 공격을 늦추는 기능만 제공하고 병종을 알지 않는다.

## 결과

자동 전투가 꺼진 RTS의 돌격 동작은 바뀌지 않는다. 다른 전투 제어 방식에 돌격을 적용하려면 그 제어부도 경직·대비·접촉 거리 계약을 연결해야 한다.

## 검토한 대안

- 명령 컴포넌트에 자동 전투 제어 분기 추가: 분리한 명령 소유권을 다시 결합하므로 선택하지 않았다.
- 애니메이션 알림으로 돌격 피해 확정: 임시 메시와 애니메이션 교체가 전투 판정을 바꾸므로 선택하지 않았다.

- 모든 병종에 돌격·대비 기능을 함께 부착: 사용하지 않는 상태와 다른 병종 의존이 쌓이므로 선택하지 않았다.
