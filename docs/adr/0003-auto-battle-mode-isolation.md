# 0003. 자동 전투를 전용 모드와 실행 주체로 분리한다

- 상태: 채택
- 관련: TABS 브랜치의 배치 후 자동 전투 프로토타입. 기존 [TASK-43 병력 선택·명령](https://app.notion.com/p/408d5512e30a81f2a3c8ee1bbb526f8b)의 RTS 조작과 병행한다.

## 동기

RTS는 전투 중 명령과 생산을 허용하지만 자동 전투는 준비 단계에서만 편성을 바꾸고 전투 중에는 관전해야 한다. 기존 전투 결과와 각 실행부의 종료는 영구적이므로 같은 액터의 종료 플래그를 되돌리면 이전 공격과 예약이 다음 전투에 섞일 수 있다.

## 결정

자동 전투는 전용 GameMode·Controller·카메라·WBP를 사용하는 맵으로 분리한다. 공통 병종·체력·피해·무장은 재사용하되 준비 상태와 자동 지휘는 전용 GameMode가 소유하고, 해당 모드의 병력은 기존 명령 Tick과 플레이어 조작 권한을 끈다. 재도전은 편성 값에서 액터를 새로 만들고 이전 전투의 투사체를 제거한다. 기존 적 역할 컴포넌트와 명령 컴포넌트에 외부 제어 모드를 추가하지 않는다.

## 결과

기존 RTS 맵과 테스트를 유지하면서 자동 전투를 검증할 수 있다. 자동 전투의 접근·경로 갱신은 별도 실행부가 되므로 공통 이동 결함을 수정할 때 함께 대조해야 하며, 이 모드는 싱글플레이 전용이다.

## 검토한 대안

- 기존 RTS Controller와 명령 큐에 자동 제어 분기를 추가한다: 플레이어 권한과 두 판단 주체가 섞이고 기존 명령·예약 동작을 함께 바꿔야 하므로 선택하지 않았다.
- 사망·종료 액터의 체력과 종료 플래그를 초기화한다: 사망 물리·타이머·발사체·명령 큐의 모든 수명을 되돌려야 하므로 편성 기반 재생성을 선택했다.
