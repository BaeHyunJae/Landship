# 0030. 실제 전장은 성 중심 카메라와 WASD 직접 주행을 사용한다

- 상태: 채택
- 관련: [TABS형 성 대결 프로토타입 제작 (TASK-53)](https://app.notion.com/p/40dd5512e30a81e08ac8c527ec57a130)

## 동기

병력을 자동 교전·성 추종으로 바꾼 전장에서 플레이어의 이동 조작을 성 하나에 집중하고, 성이 항상 화면 중앙에 보이게 한다.

## 결정

전장 설정에 지정된 실제 성을 W/S 전진·후진, A/D 차체 회전으로 직접 주행한다. 기존 이동 컴포넌트의 충돌·가속과 아군 밀어내기를 재사용하고 경로 명령을 차단한다. 포커스가 없거나 키보드 입력이 허용되지 않으면 입력을 지운다.

기존 전장 카메라 각도와 줌을 유지하며 물리 이동 이후 성 중심을 추적한다. 수동 화면 이동과 다른 선택 대상·미니맵으로의 초점 이동을 막는다. 무장 단축키는 W와 충돌하지 않도록 1·2·3으로 옮긴다. 무장의 대상은 ADR-0005와 같이 전장 설정의 성을 사용한다.

## 결과

성의 직접 주행은 경로 탐색을 기다리지 않으며 장애물에 대한 충돌 스윕을 따른다. 전장 설정이 없는 기존 조작 맵은 기존 입력을 사용한다. ADR-0005의 Q/W/E 키 지정과 병력 명령 유지 부분은 이 결정으로 대체하고, 성 참조·수명·전투 종료 검사는 유지한다.

## 검토한 대안

- 매 프레임 성 앞 지점으로 이동 명령을 갱신한다. 직접 주행 입력에 불필요한 경로 계산과 명령 교체가 발생한다.
- 성의 월드 위치를 직접 변경한다. 기존 이동 가속·제동과 충돌 처리 경로를 우회한다.
