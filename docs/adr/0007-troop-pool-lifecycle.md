# 0007. 자동 전투 병력의 생명별 풀 초기화

- 상태: 채택
- 관련: 자동 전투의 다른 병종에도 객체 풀 적용

## 동기

편성의 반복 배치·삭제·복원은 같은 병력과 AIController를 반복 생성한다. 화살의 공통 대여·보관 연산은 사용할 수 있지만 병력은 체력·랙돌·명령·시야와 일회성 행동을 별도로 복구해야 한다.

## 결정

TABS 기본 병력은 클래스·병종별 전용 풀을 사용하고 화살과 같은 저장소 도우미의 세대별 대여 검사를 공유한다. 컴포넌트의 공개 초기화 함수를 통해 새 생명을 준비하며 `BeginPlay`는 재실행하지 않는다. 같은 AIController는 풀 수명 동안 유지한다. 현재 성과 맵 배치 액터, RTS 생산 경로와 커스텀 클래스는 자동 편입하지 않는다.

## 결과

체력·공격의 일회성 초기화 계약에 풀 전용의 명시적 정리 경로가 추가된다. 알림 실행 중 반환은 거부하며 외부 구독은 다음 생명에 자동 승계하지 않는다. 사망은 기존 시체 유지 시간을 거쳐 반환하고 편성 정리는 즉시 반환한다. 이전 생명의 화살은 발사자와 공격 알림을 새 생명으로 해석하지 않는다. 병력 포인터와 AIController가 파괴되지 않을 수 있으므로 전투 제어부가 편성 소유와 풀 소유를 구분해야 한다. 실제 생성·재사용 비용은 별도 측정한다.

## 검토한 대안

- 화살 풀에 병력까지 통합: 타입별 초기화와 소유권이 하나의 큰 시스템에 섞인다.
- `BeginPlay` 재호출: 컴포넌트 등록과 외부 구독·전투 초기화가 중복된다.
- 매번 행동 컴포넌트를 교체: 보관 객체를 재사용하면서도 구성 객체를 계속 생성하게 된다.
- 모든 배치/생산 액터 자동 편입: 기존 RTS의 선택·부대 지정과 임의 블루프린트 상태 초기화까지 적용 범위가 확대된다.
