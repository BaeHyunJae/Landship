# 0011. 일반 투사체의 물리 차폐와 사격 위치 판단은 공통 발사 경로를 따른다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

사용자는 일반 궁수와 터렛의 탄환이 실제 벽에 막혀 지형을 이용한 사격 위치 선택이 의미를 갖기를 요구했다. 사거리만으로 멈추거나 성을 우선하면 벽을 향해 계속 발사하고, 터렛은 노출된 병력이 있어도 가려진 성만 고를 수 있으므로 명중과 사격 계획이 같은 차폐 기준을 사용한다.

## 결정

일반 궁수·터렛의 투사체는 `LSObstacleProjectile`을 막는 실제 지형에 차단되며, 사격 위치·표적 자격은 `ULSBasicAttackComponent::HasClearAttackPathFromLocation()`으로 후보 액터 중심에서 목표 중심까지 실제 투사체 반경을 검사한다. 이 질의는 준비 전·사망·피해 정책상 거부되는 전투 몸체를 통과하고, 피해를 허용하는 고정 시설과 오폭을 허용한 같은 진영 Pawn을 차폐로 보며, 상대 Pawn과 전투 몸체가 아닌 Pawn은 이동 계획의 일시적 장애물에서 제외하되 실제 발사체의 명중 정책은 유지한다. `Controls`와 `Enemies`는 기존 영역·경로 제한 안의 NavMesh 후보에 실제 액터 중심 높이를 더해 사격 위치를 고르고, 이동하지 않는 터렛은 이 질의를 통과한 대상 중 성을 우선하며 주황색 위협 표시에도 같은 발사 경로 조건을 적용한다.

## 결과

기존 사거리 안에 있어도 합법적인 발사 위치가 없으면 공격할 수 없고, 맵은 실제 차폐 몸체의 채널 응답을 사격 계획과 맞춰 관리해야 한다. 계획에서 제외한 상대 Pawn이 발사 뒤 탄환을 가로막거나 목표가 이동할 수 있으므로, 열린 계획 경로가 의도한 목표의 명중을 보장하지 않는다.

## 검토한 대안

- 사거리만으로 사격 가능 여부와 성 우선순위를 결정한다: 물리적으로 막힌 위치에서 대기·발사하거나 가려진 성 때문에 노출된 병력을 무시하는 문제가 남는다.
- 이동 계획에서 모든 Pawn을 항상 차폐로 본다: 이동하는 상대와 일시적인 군중까지 고정 지형처럼 회피하게 되므로, 실제 피해를 허용하는 같은 진영의 사격 차단과 구분한다.
