# 0026. TABS 프리셋 버전 4에서 자폭병을 저장한다

- 상태: 채택
- 관련: ADR-0025, TABS 자폭병 추가

## 동기

이전 편성 파일을 유지하면서 자폭병 비용과 배치를 저장해야 한다.

## 결정

버전 4는 기존 병종 순서 뒤에 자폭병을 추가한다. 버전 1부터 3까지는 각 버전의 병종 수를 검사하고 빠진 비용만 기본값으로 채운다.

## 결과

기존 편성은 새 코드에서 불러올 수 있다. 새로 저장한 편성은 버전 4를 읽는 코드가 필요하다.

## 검토한 대안

- 버전 3에 병종을 추가한다. 같은 버전의 비용 배열 길이가 달라져 형식 검증이 모호해진다.
