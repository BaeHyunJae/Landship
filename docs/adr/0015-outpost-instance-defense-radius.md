# 0015. 거점의 방어 반경은 맵 인스턴스에서 조정할 수 있다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

같은 거점 클래스를 쓰는 지역도 입구와 수비 배치에 맞는 서로 다른 방어 구역이 필요하다. 클래스 기본 반경만 편집하게 두면 맵이 배치한 각 거점의 수비 범위를 직접 정할 수 없으므로, 거점의 전투 수치와 별개인 구역 설정을 인스턴스에서 조정하도록 한다.

## 결정

거점의 `DefenseRadius`는 클래스 기본값을 상속하되 맵에 배치한 인스턴스에서 덮어쓸 수 있으며, 담당 Guard의 이동 구역과 초기 배치 검사는 모두 그 인스턴스의 같은 반경을 사용한다. ADR-0010의 거점 없는 비전투 수비 기준점 모드와 거점 지원 규칙은 유지한다. ADR-0003의 배치 프리셋은 계속 Transform만 바꾸며 방어 반경을 배치안별 전투 수치로 바꾸지 않는다.

## 결과

맵은 클래스 기본값 외에 거점별 반경 재정의와 담당 수비병 배치를 함께 관리해야 한다. 같은 반경을 이동 제한과 초기 배치 검증에 쓰므로 반경을 줄이면 기존 수비병 배치가 구역 밖이 되어 재배치가 필요할 수 있다.

## 검토한 대안

- 방어 반경을 클래스 기본값에서만 정한다: 같은 클래스로 배치한 거점마다 서로 다른 지역 수비 구역을 맵에서 직접 지정할 수 없다.
