# 0003. 전장 배치안은 고정 액터의 에디터 Transform 프리셋으로 저장한다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

동일한 지형과 전투 수치를 유지하면서 적·장애물 위치만 바꿔 비교해야 한다. 담당 거점 참조와 액터 구성을 유지하고, 에이전트 연결 없이도 동료가 같은 배치를 재현할 수 있어야 한다.

## 결정

전장에 고정 배치한 액터에 고유 ID를 연결하고, 배치안마다 모든 대상의 월드 Transform을 맵의 편집 전용 액터에 저장한다. 에디터에서 선택한 배치를 적용한 뒤 새 PIE로 검증하며, 편집 액터는 쿠킹에서 제외하고 저장된 실제 배치만 플레이에 사용한다.

## 결과

이 방식으로 클래스·개수·전투 수치가 다른 배치나 플레이 도중 전환을 표현하지 않는다. 그러한 비교가 필요해지면 배치 데이터와 적용 방식의 범위를 별도로 확장해야 한다.

## 검토한 대안

- 배치별 서브레벨·레이어를 교체한다: 현재 비교는 위치만 달라 고정 액터 참조를 유지하는 Transform 적용으로 충분하다.
