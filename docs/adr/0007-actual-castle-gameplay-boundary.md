# 0007. 실제 게임 성은 ALSCastle에 모으고 MobileCastle은 이동 시험 전용으로 둔다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

실제 게임의 성과 병력 이동을 시험하던 성이 서로 다른 클래스와 수치 경로를 사용하면서, 시험용 성에 무장·입력·생산 기능이 의존하게 됐다. 사용자가 지정한 실제 게임 성을 기능의 기준으로 유지하고 시험용 클래스의 역할을 분명히 하기 위해 경계를 나눈다.

## 결정

실제 게임의 성 기능과 그 기본 컴포넌트는 `ALSCastle`이 소유하고, 전장 설정은 이 클래스 또는 그 파생 클래스만 플레이어 성으로 받는다. 실제 성은 기존 `FLSCastleStatRow`와 공통 체력 초기화 경로를 유지하며, `ALSMobileCastle`은 병력 기반 이동 시험 전용으로 남기고 실제 성 기능을 추가하지 않는다. 이 경계는 `Castle` 계약과 `ALSBattlefieldSetup::GetConfigurationError()`가 강제한다.

## 결과

병력 이동 시험용 성을 실제 게임 성 대신 재사용할 수 없다. 전장·입력·HUD·생산과 자동화 테스트 구성은 실제 성의 타입·수치·수명 계약에 맞춰 함께 유지해야 한다.

## 검토한 대안

- 시험용 `ALSMobileCastle`에 실제 성 기능을 계속 붙인다: 실제 게임 성은 `ALSCastle`이며 시험용 클래스에는 기능을 추가하지 않는다는 사용자 지시와 맞지 않는다.
