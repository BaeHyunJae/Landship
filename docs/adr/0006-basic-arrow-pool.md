# 0006. 궁병 기본 화살의 월드 단위 재사용

- 상태: 채택
- 관련: 궁병 화살을 오브젝트 풀로 재사용하는 작업

## 동기

궁병이 반복 사격할 때마다 액터와 동적 머티리얼을 생성·제거한다. 사격 판정은 유지하면서 같은 월드에서 이 객체들을 재사용한다.

## 결정

전투 공통 월드 서브시스템이 클래스별 화살을 대여·반환하고 작은 저장소 도우미가 세대별 대여와 유효 비활성 항목 꺼내기를 맡는다. 궁병은 이를 사용하고 자동 전투 정리는 비행 중인 화살도 반환한다. 임의의 블루프린트 상태를 초기화할 수 없으므로 기본 화살만 지원하며 파생 클래스는 초기화 계약을 구현한 뒤 명시적으로 참여한다. 성 무장과 적·Niagara는 이번 적용 범위에 포함하지 않는다.

## 결과

명중·수명 종료가 액터 제거를 뜻하지 않으며 외부에서 화살 포인터를 영구 사격 ID로 사용할 수 없다. 일반 반환은 객체와 발급 세대를 검증하고 대여를 먼저 소비한다. 실제 객체의 공개 lifecycle이 수명 타이머·구독·비행 상태를 정리하며 풀은 전투 수치를 알지 못한다. 대기 화살 수를 제한하되 활성 발사는 제한하지 않는다. 첫 일제 사격의 사전 생성은 시작 단계로 생성 비용을 옮기는 것이며 전체 비용 제거를 보장하지 않는다. 성능 개선 수치는 대상 게임에서 별도로 측정해야 한다.

## 검토한 대안

- 병력별 풀: 병력 사망 시 발사된 화살의 수명이 얽히고 대기 객체를 공유하지 못한다.
- 모든 투사체를 일괄 재사용: 성 무장과 커스텀 클래스의 별도 상태 초기화까지 범위가 넓어진다.
- 매번 생성·제거 유지: 구현은 단순하지만 반복 생성 비용이 남는다.
