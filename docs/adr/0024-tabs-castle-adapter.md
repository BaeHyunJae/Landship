# 0024. TABS 자동 전투 성을 Match 전용 파생 클래스로 분리한다

- 상태: 채택
- 관련: PR #32를 TABS 브랜치에 통합

## 동기

ADR-0007은 실제 전장 성을 ALSCastle에 모으고 이동 시험용 성의 무장을 제거한다. 별도 TABS 실험 모드는 병력 기반 이동과 자동 무장을 사용하므로 기존 시험 클래스에 기능을 되붙이지 않고 경계를 유지해야 한다.

## 결정

TABS는 Match의 ALSAutoBattleCastle을 사용한다. ALSMobileCastle의 시험용 이동 몸체를 상속하고 자동 전투 무장만 소유하며 실제 전장 성이나 전장 설정의 대체 타입으로 사용하지 않는다.

## 결과

TABS 편성 및 관전 코드는 전용 타입을 참조한다. 실제 게임 성의 이동·명령 기능은 ALSCastle에 유지되며 두 모드의 성은 별도로 관리한다.

## 검토한 대안

- ALSMobileCastle에 무장을 복원한다: ADR-0007의 시험 클래스 경계를 훼손한다.
- TABS 성을 즉시 ALSCastle로 교체한다: Character 기반 접근 계획과 편성 좌표까지 변경해야 하므로 PR 통합 범위를 넘어선다.
