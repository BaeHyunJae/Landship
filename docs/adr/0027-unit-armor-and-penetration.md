# 0027. 방어력과 관통력을 공통 피해 처리에서 적용한다

- 상태: 채택
- 관련: [전투 기반 클래스와 공통 규칙 구현 (TASK-39)](https://app.notion.com/p/408d5512e30a81d09f90ceea29d8fac8)

## 동기

방패병과 창병의 상성을 수치로 조정하면서 근접 공격, 화살, 포격, 돌격에 같은 피해 계산을 적용해야 한다.

## 결정

병력 수치 행에 방어력과 관통력을 추가하고 기본값을 0으로 둔다. 체력 컴포넌트는 초기화와 풀 재사용 때 두 값을 준비한다. 피해 요청은 생성 시 공격자의 관통력을 복사하고, 명중 시 대상의 방어력에서 관통력을 뺀 만큼 피해를 감소시킨다. 유효 방어력은 0 이상이며 감소 후 피해는 원래 피해와 1 중 작은 값 이상이다. 방패의 화살 차단은 명중 처리에서 우선한다. 자폭병 자체 소모는 명시적으로 방어력을 무시한다.

## 결과

투사체가 비행하는 동안 발사자가 제거되거나 풀에서 재사용되어도 관통력은 발사 시 값을 유지한다. 기존 수치 행과 체력 초기화 호출자는 0 기본값을 사용한다. 방어력은 치유량에 적용하지 않는다.

## 검토한 대안

- 창병이 방패병에게만 추가 피해를 준다. 다른 방어 대상과 병종 조정마다 개별 상성 분기가 필요하다.
- 각 공격 컴포넌트에서 방어력을 계산한다. 투사체와 즉시 공격의 규칙이 달라지거나 중복 적용될 수 있다.
