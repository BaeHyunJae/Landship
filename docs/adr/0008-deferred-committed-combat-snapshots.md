# 0008. 확정 전투 사건은 수명과 분리한 스냅샷으로 다음 틱에 전달한다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

실제 피해와 지뢰 폭발은 필수 사망 처리나 공개 알림 도중 관련 액터가 제거돼도 이미 일어난 사건이다. UI 반응과 지역 경보가 액터의 현재 상태를 다시 읽거나 제거되는 액터에 묶인 타이머에 의존하면, 치명 피해나 피해 대상 없는 폭발을 놓칠 수 있다.

## 결정

폴더를 넘어 UI 반응과 지역 경보에 전달하는 피해 확정·지뢰 폭발 알림은, 사건 시점의 식별자·수치·진영·위치를 보관한 스냅샷과 약한 수신자 바인딩을 월드 타이머에 복사해 다음 틱에 전달한다. 소비자는 스냅샷으로 사건을 판정하고, 현재 액터를 사용할 때만 약한 참조와 전투 진행 상태를 다시 확인한다. `ULSHealthComponent::OnDamageCommitted`와 `ALSMine::OnMineExploded`가 이 경계를 제공하며, 기존 즉시 체력 알림과 필수 사망 처리의 순서는 유지한다.

## 결과

소비자의 반응은 피해 적용 호출과 같은 스택에서 완료되지 않으며 다음 틱까지 늦어진다. 소비자는 액터 제거 뒤에도 유효한 사건 식별자를 유지하고, 필요한 기하·진영 정보가 요청 생성 시점에 보관됐는지 검사해야 한다.

## 검토한 대안

- 소비자가 현재 공격자·수신자의 위치와 진영을 다시 조회한다: 액터가 제거되거나 이동한 뒤에는 이미 확정된 사건의 조건을 복원할 수 없다.
- 지뢰 폭발을 피해 알림으로만 추론한다: 실제 피해 대상이 없는 폭발은 기록되지 않고, 폭발과 해제를 구분하는 사건 경계도 잃는다.
