# 0023. 의무병 지원 행동과 편성 형식 확장

- 상태: 채택
- 관련: 치유 빔을 사용하는 의무병 추가

## 동기

아군 한 명을 치유하는 의무병을 추가하려면 적만을 대상으로 하던 자동 전투 제어와 세 병종을 저장하던 편성 형식을 확장해야 한다.

## 결정

병종 전투 컴포넌트가 지원 행동 여부를 제공하고, Match는 지원 병종에 같은 진영 목록을 전달해 이동을 실행한다. 의무병 컴포넌트는 환자 선택·회복·빔 표시를 맡고 체력 변경은 공통 체력 API에 위임한다. 병종 enum 뒤에 의무병을 추가하고 JSON 버전 2에서 네 병종 비용을 저장한다. 버전 1을 읽을 때 기존 세 병종 값을 유지한 채 새 병종 비용만 추가한다.

## 결과

공격 실행에 음수 피해를 넣지 않으며 회복 알림과 피격 알림이 분리된다. 환자의 풀 생명 세대를 확인하고 반환·전투 종료 시 빔을 정리해야 한다. 기존 저장 파일은 새 코드에서 읽을 수 있지만 새 형식은 구버전 실행 파일에서 읽을 수 없다. 현재 빔은 거리로만 연결하며 지형 차폐·우버차지·초과 회복은 제공하지 않는다.

## 검토한 대안

- 기본 공격의 피해를 음수로 사용: 피해 정책·피격 반응·공격자 알림과 회복이 섞인다.
- 의무병이 이동까지 독자 처리: 공통 전투 제어부와 경로 요청이 중복된다.
- 기존 편성 파일 폐기: 병종 추가만으로 팀의 배치 자료를 잃게 된다.
