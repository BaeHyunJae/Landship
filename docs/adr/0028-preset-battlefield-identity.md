# 0028. TABS 프리셋에 전장 식별자를 저장한다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

같은 좌표의 편성도 선택한 지형에 따라 배치 가능 여부가 달라진다. 프리셋을 불러올 때 저장 당시 전장을 함께 복원해야 한다.

## 결정

기존 JSON 프리셋에 선택적 battlefield 필드를 추가한다. 평지는 flat, 변형 전장은 지형 패키지 경로로 식별한다. 배열 순서나 화면 표시 이름은 저장 식별자로 사용하지 않는다. 필드가 없는 이전 프리셋은 현재 전장에 적용한다.

다른 전장인 경우 지형 교체와 NavMesh 준비가 끝난 뒤 저장 편성을 적용한다. 편성 적용에 실패하면 이전 전장과 편성의 복구를 시도한다. 지형이나 NavMesh 준비 자체가 실패하면 Error 상태로 원인을 표시한다.

## 결과

지형 패키지 경로를 바꾸면 저장 식별자의 이전 경로를 처리해야 한다. 불러오기 성공 반환은 다른 전장에 대해서는 비동기 요청 수락을 뜻하며, 실제 완료는 상태 변경과 메시지로 알린다.

## 검토한 대안

- 전장 선택 인덱스를 저장한다. 선택 목록 순서를 바꾸면 다른 맵을 불러올 수 있다.
- 프리셋에 편성만 저장한다. 지형에 맞지 않는 좌표가 거부되어 같은 전장을 수동으로 찾아야 한다.
