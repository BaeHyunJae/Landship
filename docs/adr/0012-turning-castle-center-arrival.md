# 0012. 선회 이동 성의 지면 이동은 성 중심을 기준으로 도착한다

- 상태: 채택
- 관련: [갈래길 맵과 적 배치안 2개 (TASK-48)](https://app.notion.com/p/408d5512e30a81558018fb980e4a4f52)

## 동기

큰 성이 목적지에서 몸체 반경만큼 떨어진 상태를 도착으로 인정하면, 플레이어가 지정한 전투 위치와 실제 성 중심이 어긋난다. 성의 위치 선택을 전투 판단에 사용하기 위해 선회·전진 이동을 쓰는 실제 성의 지면 이동 도착 의미를 분명히 한다.

## 결정

`ALSCastle`이 `bTurnBeforeForward`를 켠 경우에만 일반 지면 이동은 보정 목적지와 성 중심의 수평 거리에 명령의 도착 허용 반경을 적용하며, 성 몸체 반경을 더하지 않는다. 명령 실행부의 완료 조건과 경로 추종기의 제동은 같은 실제 도착 경계를 사용한다. 기본값은 false로 유지하여 기존 성·병력 이동과 별도 공격 접근의 도착 규칙은 바꾸지 않으며, ADR-0004의 몸체별 내비게이션 선택도 유지한다.

## 결과

선회 이동 성은 몸체 반경만큼 떨어진 지점을 도착으로 처리하지 않으므로 목적지 중심 쪽으로 더 이동한다. 명령 실행부와 경로 추종기를 바꿀 때 중심 도착과 제동 경계가 다시 어긋나지 않도록 함께 유지해야 한다.

## 검토한 대안

- 선회 이동 성에도 기존 에이전트 반경을 더한 도착 판정을 유지한다: 큰 성의 중심이 지시한 위치까지 이동하지 않아 전투 위치 선택의 의미가 흐려진다.
- 모든 성과 병력의 도착 판정을 동시에 바꾼다: 이번에 지정한 선회 이동 성의 범위를 넘어 기존 이동 계약까지 바꾼다.
