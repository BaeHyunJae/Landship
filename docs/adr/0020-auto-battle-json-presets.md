# 0020. 자동 전투 준비 편성의 JSON 프리셋

- 상태: 채택
- 관련: [병력 작업](https://app.notion.com/p/408d5512e30a81d09f90ceea29d8fac8)

## 동기

전투 배치를 반복 시험할 때 맵의 적 배열을 수정하고 에디터를 다시 실행하는 절차가 느리다. 팀원이 편성을 공유하고 변경 내용을 비교할 수 있는 저장 형식이 필요하다.

## 결정

준비 단계의 양측 병종·지면 좌표·성 위치·무장·아군 예산·인구 상한·병종 비용을 버전이 있는 UTF-8 JSON 프리셋으로 저장한다. 파일 이름은 경로가 아닌 제한된 사용자 이름이며 프로젝트 Saved의 AutoBattlePresets 폴더에서 관리한다. 액터 ID·현재 체력·쿨타임·전투 진행은 저장하지 않는다.

## 결과

불러올 때 데이터와 현재 전장의 배치를 검사하고 새 준비 액터로 교체한다. 맵 경계와 NavMesh가 다른 곳에서는 같은 프리셋을 사용할 수 없을 수 있다. 파일은 Git에 자동 포함되지 않으므로 공유할 때 JSON을 별도로 전달한다. 기존 파일 교체는 명시적인 덮어쓰기 요청으로 구분한다.

## 검토한 대안

- SaveGame 바이너리: 편성은 작은 데이터이고 텍스트 비교와 수동 편집의 이점이 커서 선택하지 않았다.
- 에디터 배치 마커만 유지: 플레이를 멈추고 맵을 저장하는 반복을 줄일 수 없어 인게임 프리셋을 주 경로로 선택했다.
