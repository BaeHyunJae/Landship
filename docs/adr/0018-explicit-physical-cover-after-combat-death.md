# 0018. 일반 투사체는 명시적으로 등록된 물리 잔해에도 차단된다

- 상태: 채택
- 관련: [포탄 조합·물리 연쇄 전투 프로토타입 제작 (TASK-52)](https://app.notion.com/p/40dd5512e30a815d9bf2f6f5afdb546d)

## 동기

ADR-0011을 대체한다. 기존 일반 투사체는 사망한 전투 몸체를 통과하지만, 포탄 조합 실험에서는 파괴 후에도 남는 수송차·철판·얼음 몸체를 재료와 엄폐물로 사용하므로 체력상 생존 여부와 실제 차폐 수명을 분리한다.

## 결정

실제 충돌 primitive를 명시적으로 등록한 물리 차단체는 일반 투사체와 공통 사격 경로 질의에서 사망·피해 허용 여부보다 먼저 실제 형상으로 차폐를 판정한다. 등록하지 않은 대상에는 기존 표적·진영·시체 통과 규칙을 그대로 적용하며 지형 차폐와 일반 사격 위치 계산도 유지한다.

## 결과

명시적 차단체의 소유자는 몸체의 생성·교체·제거와 충돌 채널을 함께 관리해야 한다. 체력이 없는 잔해도 사격을 막을 수 있으므로 공격 가능한 표적과 물리 차폐를 같은 개념으로 취급하지 않는다.

## 검토한 대안

- 모든 사망 액터를 차폐로 바꾼다: 개선 실험 밖의 시체 통과 동작까지 바뀌므로 적용하지 않는다.
- 공통 체력에서 잔해를 생존 상태로 유지한다: 승패와 사망 판정의 계약을 깨므로 적용하지 않는다.
