# 전장 맵 계약

## 제공하는 것

- `ALSBattlefieldSettings`는 지도와 시야가 공유하는 전장 경계와 지형 목록이다. 시야·미니맵을 쓰는 맵에는 하나만 배치한다. 액터의 위치·회전·크기는 경계를 바꾸지 않는다.
  - `BoundsMin`, `BoundsMax`: 월드 XY 사각 경계. 유한하고 양의 크기여야 한다.
  - `GroundHeight`: 지면 기준 높이. 미니맵 입력의 지면 높이와 카메라 초점 높이로 쓴다.
  - `TerrainActors`: 미니맵 지형 캡처에 포함할 정적 지형 액터만 직접 등록한다. 같은 월드의 유효한 액터여야 하고 `ULSVisionParticipantComponent`를 가지면 안 된다. 전투 액터는 넣지 않는다.
  - `FogMaterial`: 안개 후처리 머티리얼. 기본값은 `M_BattlefieldFog`다.
  - `VisionRefreshInterval`, `VisibilityTextureWidth`, `OutsideDarkness`: 시야 갱신 주기, 가시성 텍스처 폭, 시야 밖 어둡기. 유효 범위는 에디터 유효성 검사가 알려 준다.
- `ALSBattlefieldSettings::Find(World)`는 유효한 설정이 정확히 하나일 때만 그 액터를 반환한다. 없거나 중복이거나 유효하지 않으면 null이다. 지형이나 경계를 추측하지 않는다. `Vision`, `Controls`(카메라 경계, 미니맵 명령)가 이 함수로 경계를 읽는다.
- 에디터 유효성 검사가 다음을 오류로 보고한다. 설정 액터 중복, 유효하지 않은 경계·렌더링 값·지형 목록, 시야 참여 컴포넌트가 없는 적 진영 액터와 경로 장애물.
- `ALSBattlefieldLayoutAuthoring`은 같은 에디터 월드에 배치한 액터들의 위치·회전·크기를 이름으로 전환한다. `Registry`는 고유한 `ActorId`와 액터 참조를, `Presets`는 배치안 이름과 모든 등록 대상의 월드 Transform을 가진다.
  - `SelectedPreset` 목록에서 고른 뒤 `ApplySelectedPreset`을 누르면 전체 설정 검사 후 한 번의 Undo로 되돌릴 수 있게 적용한다. 선택만으로 배치가 바뀌지는 않는다. 액터를 생성·제거하거나 클래스·병종·역할·담당 거점·전투 수치를 바꾸지 않는다.
  - `ValidateLayout`과 `GetConfigurationError()`는 설정 오류를 보고한다. 빈 이름·중복·누락·다른 월드 참조·자기 참조·부착 관계·루트 없는 액터·유효하지 않은 Transform은 오류다. 어떤 배치안에든 오류가 있으면 적용 전에 거절하고 등록 액터를 바꾸지 않는다. 데이터 검사는 PIE 여부와 분리하며, 적용 직전에만 편집 월드·플레이 상태도 확인한다.
  - `GetMatchingPreset()`은 현재 액터 배치와 일치하는 첫 프리셋 이름을 반환하고, 혼합 배치이거나 데이터가 잘못되었으면 None이다. `ValidateLayout`은 현재 일치하는 배치와 선택값이 다른지도 알린다. 실제 에디터에서 적용하면 성공·실패 알림을 표시한다.
  - 편집 액터는 쿠킹에서 제외된다. 저장한 일반 액터 배치가 플레이에 사용되며 런타임 배치 로더는 없다.
- `/Game/Landship/Maps/L_BattlefieldPrototype`은 세 진격로·중간 횡단로·공통 최종 합류가 있는 전장이다. 현재 `BattlefieldLayout`에는 완전한 기준 배치 `V0` 하나를 저장한다.
  - 성·핵심 거점·전장 설정·내비게이션·지형은 공통이며, 프리셋은 비핵심 거점·적 병력·경로 장애물의 고정 액터를 참조한다.
  - 지형은 Maps 소유 MaterialInstance로 바닥과 차단 영역을 구분하고 `TerrainActors`에 함께 등록한다. 전투 액터는 지형 캡처에 넣지 않는다.
- `/Game/Landship/Maps/Blueprints/BP_BattlefieldCastle`은 실제 게임 성인 `ALSCastle` 파생이다. 기존 `DT_CastleStats`의 `BattlefieldPrototype` 행과 `Castle/Data`의 `DA_Cannon`·`DA_Shotgun`·`DA_Ballista`를 사용한다. 맵 전용 스탯 표나 무장 복사본을 원본으로 두지 않는다.
- `ALSBattlefieldEncounterCoordinator`는 명시한 지역과 병력·시설·지뢰 소속을 관리한다. 살아 있는 아군의 진입, 소속 대상에 대한 실제 아군 피해, 소속 지뢰의 실제 폭발로 해당 공격대만 한 번 활성화한다. 해제와 일반 지원 요청은 출격 원인이 아니다. 지역의 `AssaultMembers` 배열이 출격 병력 소속과 규모의 원본이며 지역마다 규모가 달라도 된다. 중앙 수비 전용 지역은 이 배열이 비어 있어야 하고 나머지 지역은 한 명 이상을 지정해야 한다.
- 지역의 `PlacementBounds`와 `AssaultPlacementBounds`는 배치 허용 영역이며 플레이어의 `EntryBounds`와 다르다. 휴면 병력의 누락·중복 소속과 영역 밖 배치는 오류다. `FixedActorIds`에 지정한 봉쇄선·수비 기준점은 배치안 사이에 고정하고, 각 프리셋의 병력·시설 이동도 지역 검사를 통과해야 한다.
- 전방 `L1`·`C1`·`R1`의 프리셋은 Guard 중심과 입구 동쪽 끝 사이에 병력 내비게이션 반경과 실제 몸체 반경을 합한 여유를 유지해야 한다. 터렛은 제안된 회전·크기를 적용한 권위 있는 루트 몸체 전체가 입구 동쪽에 있어야 한다. 이 검사는 프리셋 적용 전 배치 검증이며 전투 중 Guard의 이동 영역을 바꾸지 않는다.
  - 전방 Guard의 수비 반경과 배치는 공통 병종의 실제 사거리와 양측 몸체 크기까지 포함해 공통 합류점과 다른 입구의 접근로를 보호한다. 공통 사거리가 바뀌면 이 공간 격리와 자기 진격로의 공격·복귀 가능성을 함께 확인한다.
- 전장 성의 AI 컨트롤러는 `ALSCastleAIController`다. `Orders`가 낸 경로 요청을 그대로 사용하면서 모서리·도착 전에 제동하고, 정지 후 자동 선회·전진한다.
- 이 맵의 `BP_BattlefieldGameMode`는 기존 컨트롤러·HUD·GameState를 유지하고 `BP_BattlefieldCamera`만 기본 Pawn으로 지정한다. 전장 전용 카메라는 큰 성과 진지를 함께 볼 수 있는 초기 줌·줌 범위를 가지며, 독립 이동·드래그·초점 이동 조작은 기존 카메라와 같다.
- `ULSBattlefieldNavigationSystem`은 이 전장의 병력용 `Troops`와 성용 `Castle` 에이전트를 내비게이션 데이터 등록 전부터 제공한다. 등록 크기와 생성 크기·계단 높이를 맞추며, 호출부는 행위자의 `GetNavAgentPropertiesRef()`에 맞는 데이터를 선택한다. 성 데이터는 `ALSBattlefieldCastleNavMesh`의 기본 해상도 10cm·윤곽 단순화 오차 0.5를 등록 전부터 사용한다. 병력은 기본 Recast의 19cm·1.3 설정을 유지한다. 전역 기본 Recast나 다른 맵의 시스템 클래스는 바꾸지 않는다.

## 동작 조건

- 전장 경계와 지형 캡처 설정은 플레이(PIE) 시작 전에 정한다. 값을 바꾼 뒤에는 플레이를 다시 시작한다.
- 설정 액터가 없는 맵은 시야 기능 없이 기존 동작을 유지한다.
- 배치안 전환은 PIE/SIE가 실행 중이거나 시작 대기 중이면 원본 에디터 월드에서도 거절한다. PIE를 끝낸 뒤 전환하고 새 PIE를 시작해야 복귀 위치·발견 이력·승패·쿨타임이 새 전투 조건으로 시작한다.
- 배치안이 비교하는 항목 외의 인스턴스 설정은 동일하게 유지한다. 무장 비활성화 같은 별도 시험 조건을 사용했다면 일반 플레이의 시작 상태로 복원한다.
- 이 전장 World Settings의 Navigation System Config는 `ULSBattlefieldNavigationSystem`을 사용한다. NavMeshBoundsVolume은 두 에이전트를 지원해야 하며 기본 데이터를 다시 설정하는 `ALSNavigationSetup`은 배치하지 않는다. 내비게이션 데이터는 해당 초기 설정으로 월드에서 생성한다.
- 성과 병력은 같은 주 진격로를 사용하지만 시설 접근에는 각자의 몸체에 맞는 경로를 쓴다. 전장 성의 물리 몸체는 반경·반높이가 모두 500cm인 구형 캡슐이다. 전장의 성 프로필·등록·생성·Pawn 선택은 논리 반경 580cm·높이 1000cm를 사용한다. 물리 반경 500cm가 통과할 수 있어도 추가 경로 여유보다 좁은 틈은 경로에서 제외될 수 있다. 내비게이션은 이 평면 통행 여유를 적용하지만, 지면 가까이 있는 병력·지뢰와의 실제 접촉 폭은 상대 몸체의 높이에 따라 좁아진다. 지뢰 접촉·회피와 배치 검사는 실제 캡슐 형상을 기준으로 한다. 임시 몸체는 사각형 외형 모서리의 정밀 충돌을 제공하지 않는다. 형상을 바꾸면 캡슐·에이전트·발사 높이·생산 위치를 함께 맞춘다.

## 하지 않는 일

- 시야 계산과 미니맵 표시는 `Vision`이 맡는다.
- 플레이어 성과 핵심 거점의 지정은 `Enemies`의 `ALSBattlefieldSetup`이 맡는다.
- 배치안 전환은 지형·전투 규칙·행동 역할을 교체하지 않는다. 클래스·개수·전투 수치가 다른 비교 실험은 별도 저작과 검증이 필요하다.
