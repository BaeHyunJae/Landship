# 조작 계약

## 제공하는 것

- 병력 풀의 `SuspendForPool`은 명령·예약·경로 구독과 넉백 상태를 정리하고 새 명령을 막는다. `ResumeFromPool`은 새 체력 생명의 피격 구독을 연결한다. 예약한 다음 틱의 명령 갱신은 생명 세대를 확인해 과거 대여의 콜백을 무시한다.

- 자동 전투 준비의 배치는 좌클릭 드래그 브러시다. 병종 선택은 생성 모드, Delete 또는 삭제 버튼은 삭제 모드를 전환한다. 생성 간격은 누적 지면 거리로 계산하고 삭제는 프레임 사이 선분과 병력 충돌 반경을 검사한다. 현재 편집 진영에만 적용하며 성은 삭제하지 않는다. 비용·환급·겹침·경계 검사는 Match 요청을 그대로 사용한다.
- Shift+클릭은 개별 병력 선택, 이후 지면 클릭은 이동이다. UI 위·포커스 상실·카메라 캡처·버튼 해제·도구/진영 변경·준비 종료는 스트로크를 끊는다. 텍스트 입력 중 Delete는 도구를 바꾸지 않는다.

### 자동 전투 전용 조작

- 준비 중 SetEditingFaction으로 아군·적을 전환하며 클릭 배치·선택·이동·삭제·초기화·성 이동·무장은 현재 편집 진영에 적용한다. 전환과 프리셋 로드는 선택을 해제한다. ID의 0만 미선택이며 음수 적 ID도 선택이다. 자원과 저장 데이터 변경은 Match의 요청이 처리한다.
- 이름·숫자 입력 중 Enter는 전투 시작 단축키로 전달하지 않는다. 저장·불러오기는 명시적인 UI 동작이며 편집 패널 위 클릭은 전장으로 전달하지 않는다. 파일 작업은 제한된 사용자 요청 때만 수행한다.


- `ALSAutoBattleController`는 RTS Controller를 상속하지 않는다. 준비 단계 좌클릭은 병력 배치·선택·이동이며 Delete는 선택 병력을 제거한다. 성은 전용 선택 뒤 지면 클릭으로 배치한다. WBP 위 클릭은 전장으로 전달하지 않는다. 게임 규칙은 Match의 요청이 다시 검사한다.
- `ALSFreeCameraPawn`은 자유 비행하는 1인칭 관전 카메라다. 우클릭을 누른 동안 WASD는 시점 기준 이동, Q/E는 하강·상승, Shift는 가속이다. 우클릭+휠은 속도 조절, 일반 휠은 시점 방향 앞뒤 이동, 가운데 버튼 드래그는 화면 평면 이동, Home은 기본 위치 복귀다. 병력은 통과하고 지형·성·건물에 충돌하며 전장 주변과 고도를 제한한다. 준비·전투·결과 모두 우클릭 또는 가운데 버튼을 누르는 동안만 커서를 캡처하고, 놓으면 원래 위치로 반환한다. 창 포커스를 잃으면 캡처를 해제하며 다른 창의 커서를 강제로 옮기지 않는다. 전투 시작 시 자동 캡처하지 않는다. Esc도 캡처를 해제한다. 전투 중 직접 명령·생산·수동 무장 입력 경로는 없다.
- 배치 미리보기의 NavMesh·겹침 검사는 제한된 주기로 수행하고 실제 클릭 때 재검사한다. 자유 관전 중과 UI 위에서는 미리보기를 검사하지 않는다.
- `ULSOrderComponent::TryCompleteKnockback()`은 착지와 최소 보류 시간이 지난 넉백 표시만 해제한다. 명령을 실행하지 않으며 자동 전투의 별도 실행부도 공통 넉백을 사용할 수 있다.

- 공격 이동은 명령 접수 시 감지 범위의 적을 즉시 확인한다. 이동 완료와 현재 표적 사망은 다음 틱에 명령 판단을 요청하고, 공격 접근 중 사거리 진입은 이동 갱신 시 확인한다. 적 행동 컴포넌트가 명령 실행을 소유하는 경우에는 이 판단을 실행하지 않는다.
- 추적은 `RepathInterval`마다 갱신하되 표적이 `TargetRepathDistance` 이상 이동하면 `MinAttackRepathInterval`(기본 0.05초) 간격으로 먼저 갱신한다. 접근 중 정지 지점은 사거리 안쪽 `AttackApproachPadding`(최대 사거리의 10퍼센트)만큼 여유를 둔다. 좁은 지형에서 도착한 경우에는 실제 사거리로 공격 가능 여부를 판단하며 피해 사거리를 늘리지 않는다.
- `ALSRTSCameraPawn`은 성이나 병력과 별개인 독립 카메라 Pawn이다. 성을 선택하거나 이동시켜도 카메라에 빙의하지 않는다. `ALSGameMode`가 기본 Pawn으로 연결한다.
  - 방향키 또는 화면 가장자리: 화면 기준 상하좌우 이동. 대각선이 더 빠르지 않다.
  - 마우스 가운데 버튼 드래그: 지면을 끄는 방향으로 이동.
  - 마우스 휠: 확대·축소.
  - 대상 선택 후 `Home`: 선택 대상들의 중심으로 초점 이동.
  - `FocusLocation(Location)`은 초점을 이동하되 경계 안으로 제한한다. `GetZoomDistance()`로 줌 거리를 조회한다.
  - 카메라 Pawn Blueprint에서 `PanSpeed`, `DragUnitsPerPixel`, `ZoomStep`, `MinZoomDistance`, `MaxZoomDistance`, `FocusHeight`, `BoundsMin`, `BoundsMax`를 조정한다. 경계는 초점의 XY 경계이며 화면 모서리가 맵 밖을 보이지 않게 하는 제한은 아니다.
  - 자유 회전과 자동 대상 추적은 없다.
  - 마우스가 게임 뷰포트 안에 있고, 뷰포트가 입력 포커스를 가지며, 전면 창일 때만 입력을 처리한다. 마우스가 가리키는 위젯이 게임 뷰포트가 아니면 카메라와 월드 클릭 입력을 막는다.
- 선택: 좌클릭은 단일 선택이고 적은 정보 확인만 한다. 좌클릭 드래그는 아군 다중 선택이며 성과 병력을 함께 고를 수 있다(성·병력이 포함되면 고정 건물은 제외, 투영한 액터 중심으로 판정). `Shift` 클릭·드래그는 추가·제외한다. 더블클릭은 화면 안의 같은 `SelectionType`(기본은 클래스)을 선택한다. HUD 위에서의 클릭은 전장 선택·명령으로 전달하지 않는다.
- 부대: `Ctrl+0~9`로 지정하고 숫자로 호출한다. 같은 숫자를 빠르게 두 번 누르면 화면을 복귀한다.
- 명령(`ELSOrderKind`): 지면 우클릭 또는 `M` 후 지면 클릭은 일반 이동(이동 중 공격하지 않음). 적 우클릭 또는 `A` 후 적 클릭은 지정 공격(사거리 밖이면 접근). `A` 후 지면 클릭은 공격 이동(교전 뒤 원래 목적지로 이동 재개). `S`는 현재 명령과 예약을 취소하고 대기(이후 감지 범위의 적을 자동 교전할 수 있음). `H`는 위치 사수(이동 없이 사거리 안에서만 공격). `Esc` 또는 입력 대기 중 우클릭은 입력 취소. 지면이 아닌 액터를 우클릭하면 지정 공격으로 해석한다(지뢰는 해제, `Obstacles` 계약).
- 이동·공격 이동의 완전 경로 탐색이 실패했을 때만 같은 Pawn NavData로 부분 경로를 진단한다. 부분 경로 끝이 실제로 남아 있는 바리케이드 몸체에 이동 몸체 반경과 도착 오차 이내로 닿으면 `BlockedByBarricade`와 `GetBlockingBarricade()`를 반환하고, 그 밖에는 `Unreachable`을 반환한다. 완전한 우회 경로가 있으면 일반 이동으로 수락한다. 바리케이드를 자동 공격하거나 파괴 뒤 이동을 자동 재시도하지 않는다.
- `ULSOrderComponent::SubmitOrder(FLSOrder, bQueue)`는 명령을 받아 수락 여부를 반환하고 실패 이유를 `GetLastFailure()`(`ELSOrderFailure`)로 알린다. 플레이어가 조작할 수 있는 액터만 받는다. 이동·공격 이동의 목적지는 NavMesh로 보정해 저장하고, 이미 보정 목적지에 있는 명령도 허용한다. 요청이 유효하지 않으면 기존 명령을 교체하지 않는다.
- `ALSCastle`이 `ULSCastleMovementComponent::bTurnBeforeForward`를 켠 경우 지면 이동의 도착 판정은 보정 목적지와 성 중심 사이의 수평 거리에 명령의 도착 허용 반경만 적용한다. 성의 몸체 반경은 더하지 않으며 제동도 실제 경로 추종 요청의 같은 도착 경계를 사용한다. 기본 성 이동과 병력 이동의 기존 도착 판정은 유지한다.
- `Shift` 명령은 기본 최대 64개를 예약한다(`QueueFull`). 위치 사수·대기 상태에서는 예약하지 않고 즉시 교체한다. 예약 명령은 실행 직전에 다시 검사한다. 이동이 실패하거나 중단된 명령은 끝내고 유효한 다음 예약을 시도한다.
- 일반 다중 이동은 선택한 모든 대상이 클릭한 한 지점으로 집결한다. 모든 대상이 한 좌표에 겹치지 않고 충돌 크기만큼 주변에 모인다. 공격 이동만 격자 목적지를 나누어 준다.
- 교전·공격 접근 중에는 병력의 RVO 회피를 끈다. 일반 이동, 새 명령, 교전 종료에서 다시 켠다.
- 투사체 병력은 사거리 안에 있어도 벽·바리케이드가 발사 경로를 막으면 기존의 제한된 공격 접근 후보에서 도달 가능한 사거리 안의 사격 위치를 찾는다. 후보는 NavMesh로 보정한 위치에 원래 액터 중심과 내비게이션 원점의 높이 차를 더해 실제 투사체 반경으로 검사한다. 지정 공격·공격 이동은 유효한 위치로 접근하며, 위치 사수는 이동하지 않고 막힌 공격을 중단한다. 사거리·시야·쿨타임·명령 예약·지뢰 회피 규칙은 그대로 적용한다.
- 지정 공격은 사거리(충돌 원통 외곽 사이 거리)에 들어갈 때까지 추적하고, 후보 접근 위치 가운데 빈 위치를 우선한다. 모두 점유 중이면 유효한 접근 위치를 유지하며 회피와 재탐색을 한다. 명령 실패 이유는 선택 정보에 표시한다.
- 거점(`ALSOutpost`)·경로 장애물(`ALSPathObstacle`)의 공격 접근은 기존 후보 중 대기 중인 같은 진영 병력·이동 성의 몸체를 피하는 완전 경로를 우선한다. 대상 몸체는 지상에 정지한 살아 있는 루트 캡슐이며, 경로 실행·양보·넉백 중인 대상은 제외한다. 처음 접촉해 있으면 몸체 사이 거리가 줄지 않는 분리만 허용한다. 피할 경로가 없으면 기존 순서의 첫 빈 도착점을 유지하고, 빈 도착점도 없으면 첫 유효 후보를 유지한다. 대기 대상을 이동시키거나 충돌·명령을 바꾸지 않으며 일반적인 군중 정체 해소를 보장하지 않는다.
- `ULSOrderComponent::ApplyKnockback(Velocity)`는 추적·이동·공격 실행을 보류하고 착지 뒤 원래 명령을 재개한다. 현재 명령과 예약은 유지하며, 넉백 중 새 명령을 받아도 강제 이동을 취소하지 않는다.
- 투영·시작 높이·접근·경로 조회는 해당 Pawn의 내비게이션 속성에 맞는 NavData를 사용한다. `GetPlannedMovementPath(OutPoints, MaxDistance)`는 생산과 길 양보가 공유하는 예상 통과 구간을 반환한다. 진행 중인 실제 경로의 남은 구간은 정지·선회 중에도 조회할 수 있다. 선회 이동을 쓰는 성이 현재 수평 속도와 다른 방향의 새 경로를 받거나 현재 제동 거리 안에 경로 추종기가 판정한 정지 경계가 있으면 현재 위치·예상 정지 위치·남은 경로 순으로 반환하며, 전체 길이를 `MaxDistance`(cm)로 제한한다. 예상 정지 위치는 실제 수평 속도와 `ForwardBrakingDeceleration`으로 계산하므로 첫 이동 틱 전에도 기존 방향의 제동 구간을 포함한다. 물리 충돌로 실제 이동이 짧아질 수 있는 보수적인 조회이며 명령·경로·속도를 바꾸지 않는다.
- 대기 아군 병력은 유효한 전장 성이 자신의 위치를 지나는 경로로 접근하면 안전한 측면으로 일시적으로 양보할 수 있다. 명령·예약·교전·해제·넉백·위치 사수가 우선하며 새 유효 명령은 즉시 양보를 중단한다. 양보는 지뢰 회피·완전 경로·물리 충돌 검사를 사용하며 안전한 자리가 없으면 이동하지 않는다. 가까운 행에서는 각 측면의 주변 아군 몸체와 진행 중인 양보 목적지를 피하도록 앞뒤 후보 간격을 따로 정한다. 가까운 행의 측면·전방 후보를 먼저 검사하고, 같은 행에서 더 멀리 전진해 비키는 두 후보를 후방 후보보다 먼저 검사한다. 이어 가까운 행의 후방 후보와 더 바깥 행의 후보를 검사하며, 한 번의 탐색은 총 14개로 제한한다. 주변 아군이 양보 중인 동안에는 같은 간격으로 다시 검사하되 안정된 정체의 탐색 상한을 소비하지 않는다. 주변 양보가 끝나면 탐색 상한을 한 번 갱신하며, 이후 지형·배치가 그대로면 상한에서 멈춘다. 자동 추종이나 아군 충돌 제거가 아니며 일반적인 밀집 해소를 보장하지 않는다.
- `ULSSelectableComponent`는 선택 분류(`Unit`/`Castle`/`Building`), `SelectionType`, 플레이어 조작 가능 여부를 가진다. 진영이 아군인 유닛·성·거점만 조작할 수 있고 적은 정보 확인만 한다. 사망했거나 체력 초기화에 실패한 전투 대상은 선택하지 않는다.
- `ALSPlayerController::GetSelectedCastle()`은 현재 선택한 `ALSCastle`을 반환한다. 대상이 파괴되면 null이다.
- 성 무장과 전장 성 상태의 대상은 실제 게임 성인 `ALSCastle`이다. `ALSMobileCastle`은 이동 검증용이며 전장 성 입력의 대체 대상이 아니다.
- 성 무장 조준: `ALSPlayerController::ArmCastleWeapon`으로 조준 상태에 들어가고 지면 좌클릭이 `ConfirmCastleWeapon`을 부른다. 조준 중에는 `ALSRTSHUD`가 대포는 사거리 원과 피해 구역 원, 산탄은 부채꼴, 발리스타는 직선을 그리고 시전할 수 없는 조준은 붉게 표시한다. 시전 직후에도 범위를 잠시 남긴다.
- `GetConfiguredBattlefieldCastle()`은 유효한 전장 설정의 성을 상시 정보 표시용으로 반환하며 사망한 성도 반환할 수 있다. `GetCastleWeaponSource()`는 조작 가능한 살아 있는 무장 대상을 반환한다. `GetSelectedArmedCastle()`은 기존 선택 조회 의미를 유지한다. 유효하지 않거나 제거된 전장 설정에서 임의의 다른 성으로 전환하지 않는다.
- Q/W/E는 병종 선택과 무관한 성 무장 키다. 키 입력은 포커스·UI 입력 조건을 확인한 뒤 한 번만 전달하며, 명령 카드 제공자는 성 무장 이외의 Q/W/E 명령을 등록할 수 없다. 생산 F1~F3은 실제 `ALSCastle` 선택이 필요하고 Tab은 기존처럼 조준을 취소한다.
- 콘솔 변수 `LS.RTS.InputDebug 1`은 선택 입력 진단을 로그로 남긴다. 기본값은 0이다.
- `ULSCommandCardComponent`(`ALSPlayerController::CommandCard`)는 선택된 병종의 명령을 고정된 5열 3행, 셀 0~14의 격자로 만든다. `BuildCard()`는 15칸을 항상 반환하고 빈 칸도 자리를 유지한다. 호출 시점은 HUD 갱신과 단축키 처리다.
  - 셀 0~3은 공통 명령이다: 이동 M, 정지 S, 공격 A, 위치 사수 H. 셀 4는 예약된 빈 칸이다. 공통 명령은 조작 가능한 선택 전체에 적용된다. 공격할 수 없는 대상(성)이면 공격 칸이 비활성이다.
  - 셀 5~14는 병종 전용 명령이다. 혼합 선택이면 `ULSSelectableComponent::SelectionType`으로 묶은 활성 병종의 명령만 표시한다. 현재 활성 병종이 선택에 남아 있으면 유지하고, 아니면 처음 조작 가능한 대상의 병종을 쓴다. Tab은 선택을 유지한 채 활성 병종만 순환하고 진행 중인 조준을 취소한다.
  - 전용 명령 한 번은 활성 병종의 제공자 중 처음 실행 가능한 하나만 실행한다. 여러 유닛의 스킬을 한꺼번에 쓰지 않는다.
  - 선택이 없거나 적 정보 확인 상태면 실행 가능한 명령이 없다.
  - `ExecuteCell(Index, Expected)`: 표시했던 칸을 넘기면 다시 `BuildCard()`로 검사해 같은 칸(ID·제공자·대상 액터)이고 활성일 때만 실행한다. 선택이 바뀐 뒤의 오래된 클릭은 거부한다. 단축키(`HandleHotkey`)와 버튼은 같은 경로다.
  - 승패가 확정되면 모든 칸이 비활성이 되고 상태 문구가 '전투 종료'가 되며 쿨타임 표시가 사라진다. 버튼·단축키·Tab 전환은 막힌다.
  - `ULSSelectableComponent::CommandGroupName`은 명령 카드 제목에 쓸 병종 이름이다. 비어 있으면 `SelectionType`을 쓴다.
- `ULSCommandProviderComponent`는 유닛에 붙여 병종 전용 스킬을 UI와 분리한다. UI에 병종 분기나 버튼을 추가하지 않는다. Blueprint나 C++ 파생 컴포넌트를 해당 유닛에 부착하며 한 유닛에 여러 개 붙일 수 있다.
  - `GetCommands(Controller)`: 안정적인 명령 ID, 제목, 셀(5~14), 단축키, 설명, 레벨, 활성 여부, 남은 쿨타임, 전체 쿨타임을 `FLSCommandEntry`로 반환한다. 자원 소모나 상태 변경 없이 조회만 한다.
  - `ExecuteCommand(Id, Controller)`: 소유권, 생존, 실행 가능 상태, 자원, 쿨타임을 다시 검사하고 실제 기능을 호출한다. 성공한 요청만 `true`를 반환한다. UI의 활성 표시를 실행 권한으로 믿지 않는다. 즉시 실행형은 여기서 실행하고, 대상 지정형은 해당 기능의 조준 상태로 들어가 대상을 확인할 때 비용과 쿨타임을 확정한다.
  - 같은 유닛의 중복 셀·ID, 셀 간 단축키 중복, 예약 입력과의 충돌은 해당 칸을 비활성으로 만들고 '설정 충돌'로 표시한다. 범위 밖 셀(5 미만 또는 15 이상), 빈 ID·제목, 음수나 유한하지 않은 쿨타임은 표시하지 않는다. 같은 병종의 같은 셀은 같은 제공자 클래스·ID·단축키를 써야 한다.
  - 예약 입력(전용 단축키로 쓸 수 없음): 공통 명령 M/S/A/H, Tab, Esc, Home, 방향키, 숫자 0~9, 보조 키 자체, 마우스·게임패드·축 입력. Shift·Ctrl 조합 스킬은 지원하지 않는다.
- `ALSPlayerController::ProduceTroop(Type)`는 현재 입력 대기를 취소한 뒤 `ULSTroopProductionComponent::Produce()`를 부르고 결과를 `GetLastProductionResult()`에 남긴다. 전투가 끝났으면 `Unavailable`을 남기고 생산하지 않는다.
- `ALSRTSHUD`는 월드 전투 피드백을 Canvas 한 곳에서 그린다. 선택 대상과 양수 피해를 한 번 이상 받은 생존 대상의 체력 막대를 합쳐 한 번만 표시한다. 선택 표식·막대·순간 공격 및 피격 효과는 현재 시야를 따르며, 다시 보이는 대상의 지속 막대만 복원하고 만료된 순간 효과는 재생하지 않는다. 막대는 실제 시각 메시 위에 표시한다.
- `ALSRTSHUD::UsesUnifiedCombatFeedback(World)`가 true이면 대상별 기존 피격 효과는 중복 실행하지 않는다. HUD는 현재 전투 액터와 이후 생성되는 액터의 공격·피해 기록을 소비하며, 실제 피해나 이동·공격 상태를 변경하지 않는다. 피격 메시의 기존 오버레이는 효과 종료·은폐·HUD 종료 시 복원한다.
- 투사체 피드백은 실제 비행 위치와 방향을 사용하며 시야 원들의 합집합 안에 있는 구간만 그린다. 화면상의 굵기는 충돌 반경을 바꾸지 않는다.
- `ALSRTSHUD::GetCommandCellRect(Index)`: 셀 번호에 대한 화면상 사각형을 반환한다. 네이티브 클릭 처리와 맵 검사가 같은 격자 위치를 쓴다. 패널 위 클릭은 전장 선택이나 명령으로 전달하지 않는다.
- `ALSPlayerController::HandleMinimapInput(Location, bRightClick, bQueue)`는 미니맵이 넘긴 지면 좌표를 처리하고 처리했으면 true를 반환한다. 좌표가 전장 경계 밖이면 false다. true를 받은 미니맵은 카메라를 옮기지 않는다.
  - 우클릭 또는 이동·공격 이동 입력 대기 중 클릭은 선택한 병력·성에 이동 또는 공격 이동 명령을 낸다. Shift(`bQueue`)이면 기존 명령 뒤에 예약하고 입력 대기를 유지한다.
  - 입력 대기 중 우클릭은 대기만 취소한다.
  - 성 무장 조준 대기 중 좌클릭은 그 지면 좌표로 무장을 발사한다.
  - 처리하지 않은 좌클릭은 미니맵이 카메라 이동으로 쓴다.
- 커서 질의는 시야에 가려진 액터와 그 부착 시각 액터를 무시한다. 선택 가능 여부(`IsSelectable`)는 현재 시야를 따르고, 시야 스냅샷이 바뀌면 선택에서 가려진 액터를 제거한다.
- `ULSOrderComponent`의 공격 접근은 표적 충돌 외곽 기준으로 사거리 안의 도달 가능한 지점을 쓴다. 공격 접근의 도착 오차는 남은 실제 사거리 여유 안으로 제한한다. 공격 접근 중에는 RVO 회피를 끈다. 일반 이동의 도착 오차는 바꾸지 않는다.

## 동작 조건

- 맵이 `ALSGameMode`(또는 파생)를 쓰면 `ALSPlayerController`, `ALSRTSCameraPawn`, `ALSRTSHUD`가 연결된다. 전용 GameMode Blueprint가 기본 Pawn을 재정의하면 `ALSRTSCameraPawn`으로 지정한다.
- 맵에 있는 `CameraActor`의 `Auto Activate for Player`는 꺼야 한다. 켜져 있으면 엔진이 그 카메라를 플레이어의 뷰 대상으로 정해 RTS 카메라 시점이 유지되지 않는다.
- 지면 컴포넌트의 Object Type은 `LSGround`로, 장애물은 이동을 막는 충돌과 내비게이션 영향이 있는 형태로 설정한다. 클릭 Trace는 `Visibility` 채널을 쓴다. 지면이 `LSGround`가 아니면 우클릭이 이동이 아니라 공격 대상 지정으로 해석된다.
- 클릭으로 고를 유닛 캡슐은 `Visibility`를 Block한다. Blueprint에서 충돌 프로필을 바꿀 때 이 응답을 유지한다.
- 명령을 받는 액터에는 `ULSSelectableComponent`와 `ULSOrderComponent`가 있어야 한다. 이동은 `AIController`가 소유한 Pawn이고 이동 속도가 0보다 커야 한다. 공격은 설정이 끝난 `ULSBasicAttackComponent`가 있어야 한다. 체력·수치 초기화가 실패하면 이동·공격을 활성화하지 않는다. 정적인 거점은 이동할 수 없다.
- 이동 명령은 NavMesh 위의 완전한 경로가 있어야 수락한다. 부분 경로는 허용하지 않는다(`Navigation` 계약).

## 하지 않는 일

- 체력·피해·진영·사망 처리는 `Combat`이, 기본 공격 실행은 `ULSBasicAttackComponent`가 맡는다. 이 폴더는 접근 이동과 명령 상태만 맡는다.
- 내비게이션 에이전트 크기와 검색 범위 설정은 `Navigation`이 맡는다.
- RVO는 NavMesh 경계 준수나 대규모 병목 해소를 보장하지 않는다. 진형 유지는 하지 않는다.
- 네트워크 복제는 구현하지 않는다.
- 적 이동은 이 폴더의 명령 큐를 쓰지 않고 `Enemies`의 별도 실행부를 쓴다. 이 폴더의 이동 로직을 고친 PR은 `Enemies`의 이동에 같은 조건이 있는지 확인한다.
