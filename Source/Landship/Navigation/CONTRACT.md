# 내비게이션 계약

## 제공하는 것

- SetPlayerDriveInput은 실제 성의 이동을 WASD용 직접 주행으로 전환한다. 기존 전진 가속·선회 속도·최대 속도를 사용하고 후진은 ReverseSpeedRatio를 적용한다. 무입력·역방향 입력에는 PlayerBrakingDeceleration으로 제동하며, 충돌 스윕과 아군 밀어내기는 유지한다. 직접 주행은 경로 명령을 사용하지 않는다.

- ULSCastleMovementComponent는 전진 스윕을 막은 같은 진영의 생존 지상 병력을 접촉 지점의 좌우로 밀어낸 뒤 남은 성 이동을 다시 스윕한다. 병력의 NavData에서 지면을 확인하고 실제 충돌 스윕으로 변위시키므로 벽·다른 몸체·통행 불가능한 지형에 막히면 성도 멈출 수 있다. 피해와 공중 넉백은 발생하지 않는다. FriendlyPushSpeed와 FriendlyPushRecovery로 밀기 속도와 자동 병력의 추종 재개 대기를 조정한다.

- `ULSSlopeMovementComponent`는 경사 속도 커브가 설정된 지상 이동에 한해 기본 최대 속도에 배율을 곱한다. 이동 방향은 AI 경로 요청 또는 직접 입력의 가속도로 정한다. 커브를 비우면 기본 속도로 동작한다.

- `LSMineAvoidance::Snapshot()`은 현재 발동 가능한 지뢰와 발동 대기 중인 지뢰의 접촉 구를 반환한다.
- `BuildSafePath()`는 병력의 수직 캡슐과 지뢰 접촉 구를 기준으로 안전 경로를 반환한다. 호출자는 반환한 경로를 그대로 이동 요청에 사용한다. 실패 시 직접 이동으로 대체하지 않는다.
- `FindDisarmPath()`는 안전 경로·해제 거리·작업 차폐를 만족하는 후보를 반환한다. `HasDisarmLine()`과 `GetDisarmDistance()`로 실제 작업 위치를 다시 검사한다.
- `ULSMineAwareMovementComponent::SetMineAvoidanceEnabled()`로 자발적 이동의 지뢰 회피를 켜고 끈다. 외력으로 인한 접촉을 무효화하지 않는다.
- `ULSCastleMovementComponent`는 `ALSCastle`의 `UFloatingPawnMovement` 기반 이동 컴포넌트다. `bTurnBeforeForward`를 켜면 현재 전진 방향으로 제동한 뒤 경로 요청 방향으로 선회하고 전진한다. 후진·옆걸음·충돌면을 따른 미끄러짐은 하지 않는다. `TurnRate`, `ForwardAcceleration`, `ForwardBrakingDeceleration`로 반응을 조정하며 최대 속도는 성 수치를 따른다. 명령·목적지·예약은 이동 호출자가 소유하고, 정지·취소는 보관한 이동 입력도 지운다. 기본값은 꺼져 있으며 이때 기존 `UFloatingPawnMovement` 이동을 사용한다.
- 성 이동 컴포넌트는 실제 캡슐 크기와 현재 속도를 RVO에 알린다. 병력이 성을 회피하는 데 사용하는 정보이며 성 자체의 전진 속도에 회피 속도를 적용하지 않는다. 지뢰 회피는 병력의 `ULSMineAwareMovementComponent`에 남는다.
- `ALSCastleAIController`의 `ULSCastlePathFollowingComponent`는 이 선회 이동을 쓰는 성이 경로 모서리와 최종 도착 경계에 앞서 제동하게 한다. 기존 경로 추종기의 도착 판정을 사용하고, 정지한 뒤 다음 방향으로 선회한다. 명령을 새로 제출하거나 도착 반경을 바꾸지 않는다. 사용할 성의 AI 컨트롤러 클래스로 명시해 연결하며 다른 성의 기본 컨트롤러는 바꾸지 않는다.
- `bTurnBeforeForward`를 켠 실제 `ALSCastle`은 생성한 NavMesh 경로의 모서리를 포털 안쪽으로 보정한다. 직접 이동·명령 이동은 `ALSCastleAIController`를 사용해야 하며, 네이티브 재탐색으로 갱신된 경로에도 적용한다. `BuildSafePath()`는 각 NavMesh 조각을 보정한 뒤 지뢰 안전성과 비용을 검사한다. 모서리 보정은 시작점·목표점과 요청에 이미 선택된 에이전트 설정을 변경하지 않는다. 전장 성의 별도 논리 여유와 생성 정밀도는 `Maps` 계약을 따른다. 엔진은 보정 거리를 포털 반폭으로 제한하며 100점을 넘는 경로에는 적용하지 않는다. 이 보정이 모든 물리 몸체의 통과를 보장하지는 않는다. 일반 병력과 선회 모드를 끈 성은 기존 경로를 사용한다.
- `ALSNavigationSetup`을 맵에 배치하면 `BeginPlay`에서 기본 내비게이션 데이터의 에이전트 반경(`AgentRadius`)과 높이(`AgentHeight`)를 맵이 지정한 값으로 바꾸고 내비게이션을 다시 만든다. 기본값은 이동 성(`ALSMobileCastle`)에 맞춘 반경 142cm, 높이 284cm다. 기본 수평 검색 범위(`DefaultQueryExtent`)도 에이전트 반경 이상으로 올린다. 경로 모서리나 도착 허용 반경 안에서 멈춘 큰 에이전트가 다음 경로의 출발점을 찾지 못해 후속 이동이 거부되는 것을 막기 위해서다.

## 동작 조건

- 월드에 유효한 NavMesh와 이동 액터에 맞는 내비게이션 에이전트 설정이 필요하다. 유효한 완전 경로가 없으면 실패를 반환한다.
- 안전 경로는 수직 캡슐 몸체를 지원한다. 지원하지 않는 몸체는 `UnsupportedBody`를 반환한다.
- 탐색량에는 상한이 있다. `SearchLimit`은 경로가 없다는 증명이 아니며 호출자는 의도와 큐를 보존한 채 정지할 수 있다.
- `ALSNavigationSetup`을 쓰는 맵에는 `NavMeshBoundsVolume`과 내비게이션 데이터가 있어야 한다. 에이전트 크기가 유한한 양수가 아니거나 내비게이션 데이터가 없으면 오류 로그를 남기고 아무것도 바꾸지 않는다.
- 이동 행위자는 자신의 에이전트 속성에 맞는 NavData로 투영·경로를 요청해야 한다. 전장 전용 시스템은 성과 병력의 두 크기를 제공하며, 기존 단일 에이전트 맵도 사용할 수 있다. 이동하는 성의 캡슐은 내비게이션 형상에 영향을 주지 않는다.
- `ALSCastle`의 기본 내비게이션 에이전트는 반경 142cm·높이 200cm다. 맵에서 성의 에이전트 크기를 바꾸면 그 실제 설정에 맞춘 내비게이션이 있어야 한다.
- 이동 요청은 부분 경로를 허용하지 않는다. 이동 불가능한 목적지는 기존 명령을 바꾸지 않고 거부한다.

## 하지 않는 일

- 명령 출처에 따른 회피 정책과 재계획 시점은 `Controls`가 정한다. 플레이어가 지시한 이동은 지뢰 회피를 끌 수 있다.
- 지뢰 피해·해제 완료·발동 상태는 `Obstacles`가 관리한다.
- 병종별 샛길을 자동으로 설계하지 않는다. 대기 아군의 일시적인 길 양보는 `Controls`가 소유하며, 일반적인 군중 회피·진형 밀집 해소를 보장하지 않는다.
