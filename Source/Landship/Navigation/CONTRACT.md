# 내비게이션 계약

## 제공하는 것

- `LSMineAvoidance::Snapshot()`은 현재 발동 가능한 지뢰와 발동 대기 중인 지뢰의 접촉 구를 반환한다.
- `BuildSafePath()`는 병력의 수직 캡슐과 지뢰 접촉 구를 기준으로 안전 경로를 반환한다. 호출자는 반환한 경로를 그대로 이동 요청에 사용한다. 실패 시 직접 이동으로 대체하지 않는다.
- `FindDisarmPath()`는 안전 경로·해제 거리·작업 차폐를 만족하는 후보를 반환한다. `HasDisarmLine()`과 `GetDisarmDistance()`로 실제 작업 위치를 다시 검사한다.
- `ULSMineAwareMovementComponent::SetMineAvoidanceEnabled()`로 자발적 이동의 지뢰 회피를 켜고 끈다. 외력으로 인한 접촉을 무효화하지 않는다.

## 동작 조건

- 월드에 유효한 NavMesh와 이동 액터에 맞는 내비게이션 에이전트 설정이 필요하다. 유효한 완전 경로가 없으면 실패를 반환한다.
- 안전 경로는 수직 캡슐 몸체를 지원한다. 지원하지 않는 몸체는 `UnsupportedBody`를 반환한다.
- 탐색량에는 상한이 있다. `SearchLimit`은 경로가 없다는 증명이 아니며 호출자는 의도와 큐를 보존한 채 정지할 수 있다.

## 하지 않는 일

- 명령 출처에 따른 회피 정책과 재계획 시점은 `Controls`가 정한다. 플레이어가 지시한 이동은 지뢰 회피를 끌 수 있다.
- 지뢰 피해·해제 완료·발동 상태는 `Obstacles`가 관리한다.

## 공용 테스트 맵

해당 없음.
